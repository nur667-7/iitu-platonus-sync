# 📱 Telegram Интерфейс (@Brifcdbot)

> Описание команд, форматов запросов, скорости ответов и UX-взаимодействия.

---

## 1. Сводная таблица команд

| Запрос / Команда | Назначение | Источник данных | Задержка |
| :--- | :--- | :--- | :--- |
| `Что на сегодня` / `/today` | Пары на сегодня с аудиториями + задачи | Academic Cache + Notion | < 100 мс |
| `Что на эту неделю` / `/week` | Расписание с пн по сб по часам + задачи недели | Academic Cache + Notion | < 100 мс |
| `Что у меня на день, по минутам` | Хронологический график пар и окна для задач | TaskPlanner + Academic Cache | < 100 мс |
| `Что на завтра` / `/tomorrow` | Расписание и список задач на завтра | Academic Cache + Notion | < 100 мс |
| `Посещаемость` / `/attendance` | Таблица пропусков по всем предметам и остаток до 20% | Academic Cache (Analyzer) | < 100 мс |
| `Оценки` / `/grades` | Текущие баллы в журнале IITU и средний балл | Academic Cache | < 100 мс |
| `Задания` / `/assignments` | Активные домашние задания из Platonus | Academic Cache | < 100 мс |
| `Что делать сейчас` / `/focus` | Подбор приоритетной задачи под свободное окно | TaskPlanner | < 100 мс |
| `Что было сделано вчера` | Список закрытых задач из Notion | Notion Tasks DB | ~ 500 мс |
| `сделал lab 4` / `/done lab 4` | Перевод задачи в статус «Выполнена» | Notion Tasks DB | ~ 600 мс |
| `Запомни: ...` | Сохранение мысли/конспекта в базу «Знания» | Notion Knowledge DB | ~ 600 мс |
| `Лаба 3 Spring до пятницы 40 мин` | Создание задачи с параметрами | Groq LLM + Notion | ~ 800 мс |
| `/sync` | В локальном polling-режиме обновляет данные сразу; в Vercel показывает облачное расписание синхронизации | Platonus REST API / GitHub Actions | зависит от режима |

## 2. Примеры ответов

### Поминутный таймлайн дня
```text
⏱️ ПОМИНУТНЫЙ ТАЙМЛАЙН НА ДЕНЬ (ЧЕТВЕРГ, 1 ОКТЯБРЯ):

📚 Расписание пар по часам:
• 10:00–10:50 — Профессионально-ориентированный иностранный язык (онлайн online 1)
• 14:10–15:00 — Профессионально-ориентированный иностранный язык (Байзак центр 209 Б.)
• 15:10–16:00 — Профессионально-ориентированный иностранный язык (Байзак центр 209 Б.)
• 16:10–17:00 — Методология исследования (Байзак центр 414 Б)
• 17:20–18:10 — Методология исследования (Байзак центр 414 Б)
• 21:30–22:20 — Управление IT-продуктами (онлайн онлайн 25)

🎯 Задачи для выполнения в окнах:
🔥 1. Подготовить отчет по IoT (40 мин)
▫️ 2. Повторить слова к тесту English
```
